# Pace Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Pace, a polished local-first personalised programming study planner with explainable priorities, capacity-safe schedules, progress tracking, sample profiles, and browser persistence.

**Architecture:** Next.js App Router client application with a typed domain layer in `lib/`, shared app shell/components, route pages, and versioned localStorage. Deterministic prioritisation and scheduling are pure functions so unit tests can prove invariants independently of the UI.

**Tech Stack:** Next.js, React, TypeScript, Tailwind CSS, Lucide React, Zod, date-fns, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-24-pace-design.md`

## Global Constraints

- Use the exact Pace visual palette and editorial direction from the spec.
- Keep all planning local and deterministic; do not imply an external AI integration.
- Enforce `scheduledMinutes <= availableMinutes` from actual sessions.
- Use integer minutes, 25–60 minute sessions, 5-minute increments, and a 90% target fill.
- Treat 24 October 2026 as the default assessment date; use actual runtime date for countdowns and a labelled demo-date override for pre-deadline validation.
- Preserve completed/skipped history during regeneration and localStorage hydration.

## Review Focus

- Assessment date equal to/past the current date: UI shows passed state and no future sessions; covered in scheduling/date tests.
- Zero or very low capacity: returns a valid empty/partial plan with warnings; covered in scheduling tests.
- Time windows and unavailable days: no overlap and no forbidden sessions; covered in scheduling tests.
- All topics high mastery or low mastery: focus shifts to retention/mixed practice or foundations; covered in priority tests.
- Browser refresh after edits: profile, sessions, and history survive hydration; covered in storage tests and browser QA.
